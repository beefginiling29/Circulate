ABOUT THE PROJECT

Science you can interact with.

CIRCULATE is designed as an offline companion to a physical circulatory-system model.

PROJECT PURPOSE

Connect observation with explanation.

The website receives or displays a selected condition and gives the visitor a visual explanation of the corresponding circulatory process. It includes scientific information, a diagram/model, and a short interactive quiz.

PHYSICAL MODEL

Designed to work beside the model.

The Experiment page provides the digital interface for changing vessel diameter and observing the simulated response. If the physical model later sends data through a compatible local interface, the same page can be adapted to display those values.

IMPORTANT

Offline means local.

All pages, styling, JavaScript, and quiz data are stored in this folder. No website hosting, API, CDN, Google Font, or internet connection is required.
